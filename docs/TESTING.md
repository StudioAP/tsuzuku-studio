## 画像境界の比較方法

合成画像を使い、4:5 / 3:4 / 1:1、全体表示／枠いっぱい、背景、単独／重ね合わせ／並置を組み合わせた6シーンで、ページごとのCanvasを横につなげたときの画素と、共通の大きいCanvasに描いた基準画像を比較しました。大きいCanvasはテスト専用です。

全体では、Canvasサイズの違いによる描画丸めのため、一部の色チャンネルに最大3/255の差がありました。判定は「最大差3/255以内、相違バイトが全体の0.1%未満」としています。**今回の6シーンではページ境界の左右8px帯の差は0**でした。JPEGはページごとに非可逆圧縮されるため、この比較はJPEGファイル同士の完全一致を求めるテストではありません。Instagram側の再圧縮も対象外です。

## Macでの再実行

通常の検証は次で足ります。npm依存のインストールは不要です。

```bash
npm run check
npm test
npm run build
```

ブラウザシナリオの再実行は任意で、Pythonのテスト用依存が必要です。アプリの実行やデプロイには不要です。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python -m playwright install chromium
```

別のターミナルでサーバーを立てます。

```bash
npm run dev
```

最初のターミナルから実行します。

```bash
python tests/browser-smoke.py --base-url http://127.0.0.1:5173/dist/
```

`npm run build` 後のdistを、開発サーバーの `/dist/` パスから配信して検証します。結果は `test-results/` に生成され、Gitには入りません。実行前の `dist/` がない場合は先にビルドしてください。

Playwright管理のブラウザではなく、インストール済みのChromiumを使う場合は `--executable` で指定できます。WebKitで試す場合は次の通りです。ただし、PlaywrightのWebKitテストもiPhone実機の代わりにはなりません。

```bash
python -m playwright install webkit
python tests/browser-smoke.py --browser webkit --base-url http://127.0.0.1:5173/dist/
```

異なる描画エンジンで画像比較が落ちた場合、許容誤差を無条件に広げず、実画像と境界位置を調べてください。今回WebKitの自動テストは未実施です。
