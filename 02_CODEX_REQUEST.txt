【目的】
iPhone内の写真を選ぶと、横長写真が複数ページにつながるInstagramの
カルーセル用画像を自動配置し、簡単に修正・書き出しできるWebアプリです。
実装済みのソース、テスト、設計書、配信用ビルドが入っています。
仕様だけの雛形ではありません。全面的な作り直しはしないでください。

【既に決まっている条件】
・最後の投稿はInstagramアプリで、書き出した画像を私が選んで行います。
・自動配置＋簡単な修正で十分です。複雑な自由編集を増やさないでください。
・アプリのログイン不要、写真のサーバー送信なし、端末間の自動同期なし。
・外部AI、認証基盤、Instagram API、クラウド画像変換、アクセス解析は追加しません。
・実写真、ファイル名、下書き、サムネイル、秘密情報を外部APIや開発ツールに
  アップロードしないでください。コードのテストには同梱の合成画像を使います。
・写真を左右で別々に切り抜かず、共通の横長レイアウトから分割する方式を維持します。
・「全体を残す」と「余白なし」の比率上のトレードオフを隠さないでください。
・1ページずつ描画し、端末のメモリ負荷を抑える設計を維持します。
・共有用ファイルを先に生成し、最終共有ボタンのクリックから直接共有を呼びます。
・共有の完了を、「写真」への保存成功や投稿成功と同一視しないでください。

【最初の確認】
1. このフォルダにpackage.jsonがあること、Gitの管理状態、既存の変更とremoteを確認。
   既存の作業や設定を消さず、別リポジトリを上書きしないでください。
2. MacのNode.jsとnpmを確認。このプロジェクトはNode.js 22.12.0以上、.nvmrcは22系です。
   Nodeがない場合は公式の導入手順と既存環境を確認し、変更前に案内してください。
   通常起動・単体テスト・ビルドにnpm依存のインストールやAPIキーは不要です。
3. npm run check、npm test、npm run buildを順に実行。
   失敗があれば原因と必要最小限の修正を示し、テストを再実行してください。
4. npm run devでMacのブラウザからデモ・写真選択・書き出しを確認。
   MacのSafariを実際に操作できない場合は、未確認として私へ確認方法を示してください。
5. 必要に応じてdocs/TESTING.mdの任意ブラウザテストを実行。
   単なる起動のためにフレームワークや大量の依存を追加しないでください。
